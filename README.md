# 视频 Cut 关键帧截取工具（本地网页版）

把一段视频里**镜头切换（cut）的位置自动找出来**，把每个新镜头的第一帧截成图片，
作为参考图 / 分镜素材使用。

- 全部处理在**本机**完成，视频复制到本机工作目录，不上传云端
- 无需安装 ffmpeg（使用 OpenCV 内置解码）
- 操作：上传视频 → 自动分析 → 预览所有关键帧 → 一键打包 zip 下载（JPEG 原分辨率）

## 快速开始

1. 双击 `setup.bat`（首次安装环境，只需一次）
2. 双击 `启动工具.bat`，浏览器自动打开 `http://127.0.0.1:8765`
3. 拖入视频，等待分析完成，调整灵敏度后点「下载所选关键帧 (zip)」

> 命令行启动：`.venv\Scripts\python.exe server.py`（端口可用环境变量 `PORT` 修改）

## 检测原理

- **逐帧扫描**：顺序解码，缩到最长边不超过 160px 的彩色图，计算相邻帧平均绝对差（MAD）。
  不再跳过中间帧，也不丢弃颜色信息；仅保留最近两张小图，缓存每帧时间戳和差异分数。
- **筛选与截图**：检测突变，抑制“突变一帧后立即恢复”的闪光，按最小镜头间隔合并相邻峰值。
  截图按零基帧编号定位，不增加时间偏移。完成首次扫描后，改参数复用分数，仅重新筛选和截图。
- **灵敏度**：把差值阈值从「8×画面基准差（保守）」线性调到「2×（敏感）」，默认适中

检测目标是硬切镜头，不是自动寻找镜头里最清晰的代表画面。剧烈运动、渐变转场等仍可能误检或漏检。
时间码优先使用解码时间戳；后端不提供有效时间戳时按帧率估算，并在结果区提示。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| 灵敏度 | 左=保守（帧少）；右=敏感（帧多，但大动作也可能被误判） |
| 保留首尾帧 | 额外在结果里加入视频第一帧和最后一帧 |
| 最小镜头间隔 | 默认 0.1 秒，可设 0～10 秒；密集剪辑可减小，0 表示不限制间隔 |
| 抑制单帧闪光 | 默认开启；真正的一帧镜头也可能被抑制，需要时关闭并减小最小间隔 |

下载后的 zip 内含：`001_00-00-03.200.jpg` 这类按序号+时间命名的图片，以及
`cuts.txt`（文件名、时间码、类型、零基帧编号对照表）。单次最多 500 张，按视频时间顺序导出。
ZIP 在磁盘生成，由浏览器原生下载，不在网页内构造整个文件的 Blob；是否保存成功请查看浏览器下载列表。

**画质说明**：zip 内为视频**原始分辨率**的 JPEG（质量 95，属于有损重编码）；页面网格里的
小图只是压缩预览，横竖屏均完整显示。单击缩略图可查看大图并单张下载。

## 结果保护与恢复

- 上传损坏文件不会删除已有视频或截图；不同上传会话相互独立。
- 重新分析期间旧结果仍可预览和下载；读取或写图失败会报告错误，不发布缺图或错位的结果。
- 快速改参数会取消旧任务，同一视频的工作线程串行处理；分析过程中也可以点击「取消分析」。
- 同一标签页刷新会恢复视频信息、检测参数和手动跳过的帧；同一视频重新分析也按帧编号保留跳过状态。
- 连接暂时中断会自动重试，连续失败后可点击「重试连接」。服务进程重启后需重新选择视频。
- `work/` 保存视频副本和已完成的结果版本，失败/取消的本次截图会清理，ZIP 响应结束后会清理临时压缩包。
  已完成结果不自动删除，以免影响其它页面或下载。需要释放空间时，先保存需要的结果并关闭工具，再删除工作目录。

## 视频预览、手动补帧与微调

分析完成后，结果上方会出现「视频预览与手动选帧」。

1. **定位画面**：播放或拖动左侧视频并暂停，右侧会显示对应的精确帧；也可输入秒数点击「定位画面」，或拖动「逐帧时间轴」。
2. **手动补帧**：用「前一帧／后一帧」确定右侧画面，点击「补入结果」。新截图标为「手动补帧」，按视频时间插入结果。
3. **微调已有截图**：点击对应卡片的「逐帧微调」，前后移动到满意的画面，再点「保存微调」替换该条目。点「退出微调」不保存本次定位。
4. **下载**：继续使用原有勾选和 ZIP 下载。时间码、帧号与图片按保存后的结果导出，重复帧不会再次添加。

以右侧精确图片和帧号为准，浏览器视频播放器的跳转不作为逐帧精度依据。
MP4 等浏览器支持的编码可直接播放；AVI 等不支持的格式会提示，仍可用秒数定位、逐帧时间轴和前后帧按钮操作。
界面帧号从 1 开始，`cuts.txt` 中的 `frame_index` 从 0 开始。

手动修改保留在当前服务会话中：刷新页面、调节检测参数及重新分析均会保留；服务进程重启后需重新上传，
尚未提供跨重启的项目恢复。分析期间不能编辑；保存失败或结果已被另一任务更新时不会覆盖旧结果。

## 常见问题

- **有些切换没截到** → 把灵敏度调高（例如 70~90），工具会自动重新分析
- **截多了 / 画面相似** → 调低灵敏度；也可以在结果里单击某张图把它标为“跳过”，
  下载时会自动排除
- **提示“无法解析该视频”** → 编码不受支持（如个别 AV1/ProRes 封装），可先用
  格式工厂等转成 H.264 的 mp4 再试
- **大视频很慢** → 首次仍需顺序解码全部画面，速度取决于编码、分辨率和硬件；
  完成扫描后再调参数可复用缓存。数值缓存约每帧 16 字节（30 fps 一小时约 1.7 MB），不含解码器及图片等开销。

## 目录结构

```
keyframe-tool/
├─ server.py           本地服务 + 检测算法（FastAPI）
├─ static/index.html   网页界面
├─ static/app.js       页面交互与会话恢复
├─ tests/              后端及页面状态回归测试
├─ setup.bat           首次安装环境
├─ 启动工具.bat        一键启动
└─ work/               运行时数据（关闭工具并保存所需结果后可删除）
```

## 开发备注

依赖：`numpy` `opencv-python-headless` `fastapi` `uvicorn` `python-multipart`
（Python 3.10+，均安装在项目内 `.venv`，不影响系统 Python）。

回归验证（后端使用标准库 unittest；前端测试另需 Node.js 18+，使用工具本身不需要 Node.js）：

```bat
.venv\Scripts\python.exe -B -m unittest discover -s tests -v
node --test tests/frontend.test.cjs
```

测试使用临时生成的视频和临时工作目录，不改动 `work/` 内已有数据。覆盖帧精度、颜色切换、短镜头、
闪光抑制、内存图片数量、任务竞争、失败结果保护、导出及页面状态恢复。

## 打包成免安装 exe（可选）

给没有 Python 环境的人使用时，可用 PyInstaller 打成单文件 exe
（exe 内置运行环境，对方双击即可用）：

```bat
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --console --name "视频关键帧截取工具" --add-data "static;static" launcher.py
```

产物在 `dist/` 目录；分发时建议附上 `使用说明.txt`。
